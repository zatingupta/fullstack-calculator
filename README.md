# Full-Stack Calculator

A full-stack calculator web application built with **React (Vite)** on the frontend and **ASP.NET Core (.NET 8)** Web API on the backend.

## Tech Stack
- **Frontend:** React, Vite, CSS
- **Backend:** ASP.NET Core Web API (.NET 8)
- **Features:** Arithmetic operations (Add, Subtract, Multiply, Divide) processed via RESTful API
